# SPEC — 재고 콘솔 GAS 수용부 (action: inv / invBoot / invClose / 야간 요약)

> 대상: **결산 GAS 프로젝트** (gyeolsan). 새 배포 금지 — 기존 `/exec` 배포에 새 버전(`clasp deploy -i`)만.
> 프런트: `acro-재고-콘솔.html` (이 리포). 5품목: 편안환·수면환·디캡슐·숙취환·반과.
> 원칙: **직원은 슬랙에 지금처럼 출고를 적고, 콘솔은 정리·대조만 한다.** 기록 정본은 재고원장 시트.

## 0. 스크립트 속성 (하드코딩 금지 — 전부 속성으로)

| 속성 | 값 |
|---|---|
| `INV_SHEET_ID` | 재고원장 스프레드시트 ID (신규 생성 또는 결산원장과 같은 파일의 별도 탭) |
| `INV_SLACK_CHANNEL` | #결산_약재입출고 채널 ID |
| `INV_LOG_CHANNEL` | 야간 요약 게시 채널 (#아크로드-로그) |
| (기존 재사용) | `APP_KEY` · 슬랙 봇 토큰 |

## 1. 시트 구조 (재고원장)

- **이벤트** 탭: `날짜 | 시각 | 작성자 | 종류(입고/채움/조립/해체/실사/취소/추적해결) | 품목 | 패키지 | 수량 | 메모 | ref`
- **마감** 탭: `날짜 | 담당 | 소진JSON | 슬랙JSON | 차트JSON | 실물JSON | 패키지JSON | 미해결건수 | 메모 | 전체JSON`
- **추적** 탭: `발생일 | 내용 | 상태(open/closed) | 해결일 | 해결자 | 해결사유`

## 2. doPost action 3종 (기존 doPost 라우터에 분기 추가)

### `action:"inv"` — 이벤트 1건 적재
콘솔이 채움/조립/해체/입고/취소/추적해결을 누를 때마다 보냄. 검증: `k===APP_KEY`.
→ 이벤트 탭 append. 실패해도 200 반환(콘솔은 로컬에 이미 저장됨).

### `action:"invClose"` — 마감 제출
payload `data`: `{date, staff, events[], slack, chart, mid, midPkg, consumption, answers, memo, warehouse, newTracks[]}`
→ ① 마감 탭 1행 append ② `newTracks`를 추적 탭에 open으로 append ③ 슬랙 요약 1줄을 `INV_LOG_CHANNEL`에 게시:
`📦 [재고마감 날짜] 담당 ○○ · 소진 편N 수N 디캡N 숙취N 반과N · 판정 ✅/⚠N건 · 추적함 +N`

### `action:"invBoot"` (doGet) — 콘솔 부팅 데이터
`GET ?action=invBoot&k=...` →
```json
{ "slackToday": {"편":1,"디캡":1,"반과":6},   // 오늘 채널 출- 메시지 파싱 합계
  "openTracks": [{"d":"...","desc":"..."}] }  // 추적 탭 open 건
```
**슬랙 파싱 규칙** (기존 약재입출고 감사 스킬과 동일):
- `conversations.history`로 오늘 00:00 KST 이후 메시지.
- `출` 로 시작하는 줄만 (`출-`, `출 -`, `출` 변형 허용). `입-`·`보-`는 제외.
- 별칭→품목: 편/편안환 · 수/수면환 · 디캡/D/디캡슐/디톡스캡슐/D캡슐 · 숙취/숙취환 · 반과/반/반하사심. 긴 별칭 우선(겹침 방지).
- `(상담)` 포함해 합산. `⭐내일` 태그 줄은 제외(다음날 합산). "취소/정정" 멘트는 직전 동일 작성자 건 차감.
- 미등록 약어는 무시하되 카운트해서 야간 요약에 "비표준 N건" 표기.

## 3. 야간 요약 트리거 (매일 22시대, 선택이지만 권장)

마감 미제출 감지: 그날 `invClose`가 없으면 `INV_LOG_CHANNEL`에 1줄 — `📦 재고마감 미제출 — 콘솔에서 마감을 눌러주세요`.
추적 탭에 3일 이상 open 건이 있으면 — `🔺 재고 추적 N건 3일 경과 — 원장 확인 필요` (경보 채널 규칙에 따라 🔺는 회의 채널로 라우팅됨).

## 4. 콘솔 쪽 연결 (이미 구현됨 — 값만 채우면 됨)

`acro-재고-콘솔.html` 상단 `CFG.GAS_URL`·`CFG.APP_KEY` 채우면:
- 부팅 시 `invBoot` 호출 → 마감 1단계에 "🤖 슬랙에서 자동으로 받아왔습니다 → [이대로 사용]" 표시 (수동 붙여넣기 폴백 유지)
- 모든 버튼이 `inv` 이벤트 전송, 마감이 `invClose` 전송. GAS 미연결/실패 시에도 로컬로 전 기능 동작.

## 5. 하드 룰

- 수량 추정·보간 금지. 파싱 불확실 건은 버리지 말고 "비표준"으로 넘길 것.
- 콘솔 응답은 항상 200 (오류를 돌려주면 프런트 폴백이 꼬임).
- 시트 append만, 삭제 없음. 취소도 취소 이벤트 행으로 남긴다 (원장 불변).
- 환자명·차트번호는 내부 시트라 허용. 외부로 나가는 요약 줄에는 넣지 않는다.

## 부록 — AI 상담·개선 의견 (260801 추가)

- 이벤트 종류에 `제안` 추가 — 콘솔 [💬 개선·문의]에서 남긴 의견. 이벤트 탭에 그대로 쌓이고, 야간 요약에 "개선 의견 N건" 1줄 포함.
- `action:"ai"`는 **결산 GAS에 이미 있는 프록시를 그대로 재사용**한다 (ANTHROPIC_API_KEY 서버 속성). 콘솔이 재고 맥락(소진·슬랙·차트·실물·교체환산·패키지 구성)을 context로 보내므로 GAS 쪽 수정 없음 — 라우터가 inv 계열과 같은 프로젝트에 있는지만 확인.

- (260801) 추적 탭에 `원인유형 | 관련자` 열 추가 — 콘솔이 해결 시 유형(슬랙 보고 깜빡/차트 입력 누락/세는 실수/기록 누락/교체 표기 누락/기타)과 관련자를 보냄. 월간·야간 요약에 "유형 TOP·3회 반복 유형은 절차 개선 신호" 1줄 포함. 취소(되돌리기) 이벤트도 빈도 집계 대상.

## 부록 2 — 제안 기능 수용 (260801)

- `invClose` payload에 `expiry`(품목별 가장 오래된 유통기한) 추가 — 마감 탭에 저장, 임박(2개월)·경과 시 야간 요약에 1줄.
- `action:"inv"`에 `kind:"입고사진"` — `photo`(dataURL)를 Drive `재고_명세서` 폴더에 저장하고 이벤트 탭에 링크 기록. 5MB 초과는 거부(200 + 무시).
- **월간 리포트 트리거 (매월 1일 09시대)**: 전월 품목별 소진 합계 · 로스율(미해결 추적 ÷ 소진) · 3중 일치율 · 실수 유형 TOP3(3회 반복 유형은 "절차 개선 신호" 표기) · 발주 이력 · 최장 스트릭 — INV_LOG_CHANNEL에 게시.
