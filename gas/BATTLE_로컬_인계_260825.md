## 1. 자동 빌드 트리거 걸기 (5분) — 이걸 안 하면 내일 또 멈춘다

260825 02:04 에 `acdBuildAll()`을 손으로 돌려 정본 504건이 시트·qa374까지 내려갔다.
**그런데 트리거가 없다.** 이 프로젝트에는 애초에 빌드 트리거 설치 함수가 없었고,
그래서 260805 이후 19일간 멈춰 있었다. 오늘 손으로 돌린 것으로 끝내면 같은 일이 반복된다.

**방법 A (권장)** — 리포 최신 `gas/build_kb.gs`를 GAS 프로젝트에 반영한 뒤 `acdBuildInstall()` 1회 실행.

**방법 B** — 편집기에서 `build_kb.gs` 의 `acdBuildAll` 아래에 아래를 붙여넣고 저장 → 함수 목록에서 골라 1회 실행.

```javascript
function acdBuildInstall() {
  ScriptApp.getProjectTriggers().forEach(function (t) {
    if (t.getHandlerFunction() === 'acdBuildAll') ScriptApp.deleteTrigger(t);
  });
  ScriptApp.newTrigger('acdBuildAll').timeBased().everyDays(1).atHour(2).create();
}
```

**확인**: 트리거 목록(⏰ 아이콘)에 `acdBuildAll` 이 매일 오전 2시로 잡혔는가.
감사는 3시대라 **빌드가 먼저 맞추고 감사가 확인하는** 순서가 된다.

## 2. 정본에 없는 시트 행 20건 떠내기 (5분)

빌드 로그가 짚어준 것: `K037` ~ `K056` **20건**이 시트에만 있고 정본에 없다.
클로드→슬랙 경로로 시트에 직접 들어온 행이다. 정본에 올려야 제자리를 잡는다.

⚠ **로그로 출력하지 말 것.** 20건이면 잘린다. Drive에 파일로 떨군다.

편집기에 아래 임시 함수를 붙여넣고 **1회 실행**한다.

```javascript
function _tmpDumpSheetOnlyRows() {
  var props = PropertiesService.getScriptProperties();
  var sh = SpreadsheetApp.openById(props.getProperty('KB_SPREADSHEET_ID'))
             .getSheetByName(ACD_CFG.SHEET_TAB);
  var vals = sh.getDataRange().getValues();
  var header = vals[0];
  var out = [];
  for (var r = 1; r < vals.length; r++) {
    var id = String(vals[r][0] || '').trim();
    if (!/^K0(3[7-9]|4\d|5[0-6])$/.test(id)) continue;   // K037~K056만
    var o = {};
    for (var c = 0; c < header.length; c++) o[header[c]] = String(vals[r][c] == null ? '' : vals[r][c]);
    out.push(o);
  }
  var name = 'KB_시트전용행_260825.json';
  DriveApp.createFile(name, JSON.stringify(out, null, 2), 'application/json');
  Logger.log('저장 완료: ' + name + ' · ' + out.length + '건');
}
```

**확인**: 로그에 `20건`으로 찍히는가. 아니면 개수를 그대로 보고할 것(추측 금지).

**끝나면 이 임시 함수는 지운다.**
