# SPEC M2 — 미답로그 (아크로드 구심로 1호)

> 작성 260728. 대상: 라인브릿지 `Code.js` (clasp 창 구현).
> 이 문서는 사양서다. 코드가 아니다. 구현 판단이 필요한 곳은 `[구현 판단]`으로 표시했다.

## 0. 한 줄 목적

**라인브릿지 AI가 "몰랐다"는 사실을 기록한다.** 지금은 KB에 없는 질문이 오면
그 사실이 어디에도 남지 않는다. 미답로그가 생기면 지식을 공급 주도(문서를 뒤져서 등재)가
아니라 **수요 주도(환자가 실제로 물었는데 없던 것부터 등재)** 로 키울 수 있다.

M4(제안 생성기)가 이 로그를 원료로 쓴다. M2 단계에서는 **조용히 쌓기만 한다.**

## 1. 범위

**하는 것**
- 답변KB 매칭 성공/실패를 판정 지점에서 기록
- 실패 → `미답로그` 탭에 1행
- 성공 → `KB사용통계` 탭에 사용횟수 +1

**하지 않는 것 (M2에서 금지)**
- 슬랙 발송 없음. 다이제스트는 M4의 일이다. (260727 슬랙 폭주 재발 방지 — 감각은 조용해야 한다)
- 정본·qa374.json·미러 어디에도 내려보내지 않음. 미답로그는 지식이 아니라 **운영 데이터**다.
- 자동 답변 생성/등재 없음.

## 2. 시트 스키마 — 새 탭 2개 (`아크로_인입원장` 스프레드시트에)

### 탭 `미답로그`

| 열 | 이름 | 내용 |
|---|---|---|
| A | 시각 | 최초 발생 시각 |
| B | 최근시각 | 같은 질문 재발 시 갱신 |
| C | 반복횟수 | 최초 1, 재발마다 +1 |
| D | 채널 | line-jp / line-tw / kakao / 기타 (구분 가능한 범위에서) |
| E | 언어 | ko / ja / zh / th / en / 기타 |

| G | 최고후보ID | 매칭 시도에서 1위였던 원본ID (없으면 빈칸) |

### 탭 `KB사용통계`

| 열 | 이름 | 내용 |
|---|---|---|
| A | 원본ID | 답변KB 시트의 키 (Q011, F003, L017 …) |

⚠ **답변KB 탭에 컬럼을 추가하지 말 것.** 빌드(`acdBuildAll`)가 답변KB 행을 다시 쓸 때
추가 컬럼 보존을 보장하지 않는다. 사용통계를 별도 탭으로 분리하면 빌드와 접점이 0이 된다.

## 3. 기록 지점과 판정 — 두 가지 구현 방식

기록 지점: **환자 메시지에 대해 KB를 참조해 답을 만드는 그 함수** 안.
라인브릿지 내부가 둘 중 어느 구조인지에 따라 방식을 고른다. `[구현 판단]`

**방식 A — 점수 기반 검색이 이미 있는 경우**
기존 매칭 로직이 "이 KB항목을 채택한다"고 판단하는 기준을 **그대로** 재사용한다.
새 임계값을 발명하지 말 것. 채택됨 → hit(원본ID). 채택 안 됨 → miss.

**방식 B — LLM이 KB 컨텍스트를 받아 자유 생성하는 경우**
프롬프트에 출력 계약을 추가한다:

```
답변 마지막 줄에 사용한 KB 항목을 [KB:Q011] 형식으로 표기하라.
여러 개면 [KB:Q011,Q089]. KB에 근거 없이 답했거나 답하지 못했으면 [KB:none].
```

브릿지가 응답에서 이 태그를 파싱 → 환자에게는 **태그를 제거하고** 발송,
태그 내용으로 hit/miss 기록. `[KB:none]` = miss.

## 4. 개인정보 마스킹 — 질문원문 저장 전 필수

시트는 비공개지만 최소화 원칙. 저장 직전에:

- 전화번호 패턴 (`01[016789]-?\d{3,4}-?\d{4}`, 국제형 `+81…` 포함) → `[전화]`
- 숫자 10자리 이상 연속/하이픈 (계좌·카드·여권 추정) → `[번호]`
- 이메일 → `[메일]`
- 질문원문 500자 초과 시 절단

이름은 패턴으로 못 잡는다. 무리하게 시도하지 말고 위 4개만. `[구현 판단]` 추가 패턴.

## 5. 중복 억제

정규화(공백·구두점 제거, 소문자화) 후 동일한 질문이 **7일 이내** 재발하면
새 행을 만들지 않고 기존 행의 `반복횟수` +1, `최근시각` 갱신.
정규화 키 비교는 미답로그 최근 200행 안에서만 (전체 스캔 금지 — 성능).

## 6. 절대 안전 규칙

1. **감각이 죽어도 팔은 움직여야 한다.** 기록 로직 전체를 try/catch로 감싼다.
   로그 실패가 환자 응대를 막거나 지연시키면 안 된다. 실패는 조용히 버린다.
2. 함수 접두어 `lwSense` (예: `lwSenseHit_`, `lwSenseMiss_`, `lwSenseMask_`).
   `lw`/`acd` 기존 심볼과 충돌 금지. Apps Script는 전역이 한 통이다.
3. **배포는 `clasp deploy -i <기존배포ID>`.** 새 배포 금지 — /exec URL이 바뀌면
   라인 리치메뉴·QR·카톡 저장링크가 전부 끊긴다.
4. `clasp push` 전에 `clasp pull`.
5. 미답로그 5,000행 초과 시 신규 기록 중단하고 비고에 사유 1행만 남김 (폭주 안전판).

## 7. 검수 시나리오 — 구현 후 이 5개를 통과해야 완료

| # | 입력 | 기대 결과 |
|---|---|---|
| 1 | KB에 있는 질문 ("주차 가능한가요?") | 미답로그 변화 없음 · KB사용통계 Q011 +1 |
| 2 | KB에 없는 질문 ("강아지 데려가도 되나요?") | 미답로그 1행, 상태=신규 |
| 3 | #2와 같은 질문 재전송 | 행 수 그대로, 반복횟수=2 |
| 4 | 전화번호 포함 질문 | 질문원문에 번호 대신 `[전화]` |
| 5 | 기록 함수에 강제 예외 (테스트용 throw) | **환자 응대는 정상 발송** |

## 8. 다운스트림 계약 (M3/M4가 의존하는 것)

- M4 제안 생성기는 `상태=신규` 행만 읽고, 초안을 만들면 `제안됨`으로 바꾼다.
- 원장 승인 후 정본 등재 세션이 `등재됨` + `등재ID`를 쓴다. 반려는 `무시`.
- `KB사용통계`는 분기별 지식 가지치기(사용 0 항목 검토)의 근거가 된다.
- **미답로그의 상태 컬럼을 M2 코드가 변경하는 일은 없다.** M2는 쓰기 전용(신규 생성·반복 갱신).

## 9. 성공 지표

가동 1주 후: 미답로그에 실제 환자발 질문이 쌓여 있고, "가장 많이 반복된 미답 3개"와
"가장 많이 쓰인 KB 5개"를 시트만 열어 답할 수 있으면 M2 성공.

## 부록 A — 인입봇·학습원장 오염 수정 (260728 원장 지시로 추가)

같은 `Code.js` 작업이므로 M2와 한 번에 처리한다. 문제는 주간 KB 리포트가 이미 실측했다.

- 학습원장에 **테스트 메시지가 실환 응대로 기록**되고 있다 — 7/21 리포트: PENDING 33건 중
  다수가 "시스템테스트/TEST-USER/E2E검증" 라벨. 7/27 리포트: 무수정 채택률 25%의 유일한
  TRUE 1건이 원장 본인 테스트 대화. **채택률 지표가 표본 0으로 오염된 상태.**
- **PENDING 85%** — 실발송 백필 경로(lwLearn)가 학습원장에 기록을 남기지 않는다.
  7/18 리포트에서 지적됐고 아직 미해결.
- 조작키 안내줄(`ㅊ`=추천답변 · `!한국어`=… · `ㄱ`=초안 발송)이 인사·이름 같은
  단순 메시지에도 무조건 붙는다.

### A-1. 테스트 오염 차단 (최우선)

다음 중 하나면 학습원장에 **기록하지 않는다** (또는 `테스트` 열 TRUE로 집계 제외):
- 발신자가 원장 3인 (임주혁·박지선·한지영 계정)
- 본문에 테스트 패턴: `시스템테스트` `TEST-USER` `E2E` `검증` `테스트입니다`
패턴 목록은 상수 배열로 상단에 둔다. `[구현 판단]` 추가 패턴.
⚠ 같은 필터를 **§3의 미답로그 기록에도 적용**한다 — 테스트 메시지가 미답로그를 오염시키면
M4 제안 생성기가 가짜 수요를 학습한다.

### A-2. lwLearn 실발송 백필

`ㅊ`/`ㄱ`/`!` 발송이 실제로 나가면 학습원장 해당 행에 상태 `SENT` + 무수정 여부 + 발송 ts를
기입한다. 발송 없이 7일 지난 PENDING은 `EXPIRED`로 마감해 영구 PENDING을 없앤다.
이게 풀려야 무수정 채택률이라는 성능 지표가 처음으로 진짜 숫자가 된다.

### A-3. 조작키 줄 조건부 표시

실제 응대가 필요한 문의에만 조작키 줄을 붙인다. 인사·이름 전달·짧은 확인(예: 문장 1개이고
물음표·문의 키워드 없음)은 요약+번역까지만. **판단이 애매하면 표시한다** — 과다 표시가
과소 표시보다 안전하다. `[구현 판단]` 휴리스틱 기준.
