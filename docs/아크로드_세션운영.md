# 아크로드 세션 운영 — 어디서 무엇이 되는가

작성 260725. 아크로드 작업을 **어느 Claude 환경에서 착수해야 하는지** 판단하는 표.
착수 전에 이 표를 먼저 본다. 안 되는 환경에서 시작하면 중간에 막히고, 그 세션의 컨텍스트는 버려진다.

## 1. 환경 3종

| | 웹 세션 (claude.ai/code) | 로컬 Claude Code (맥/윈도우 앱·터미널) | Cowork |
|---|---|---|---|
| 실행 위치 | 클라우드 컨테이너(휘발성) | 원장 PC | 클라우드 |
| 리포 | 세션 시작 시 fresh clone | 로컬 폴더 그대로 | — |
| 커밋 안 한 파일 | **세션 종료 시 소멸** | 남는다 | — |

## 2. 능력표

| 하려는 일 | 웹 세션 | 로컬 | 비고 |
|---|:---:|:---:|---|
| Drive 정본 읽기·문서 생성 | ✅ | ✅ | 커넥터 |
| PubMed 조회 | ✅ | ✅ | 커넥터. 무료 |
| Slack 채널 조회·발송 | ✅ | ✅ | 커넥터 |
| Notion / Canva | ✅ | ✅ | 커넥터 |
| 리포 파일 편집·커밋·PR | ✅ | ✅ | 웹은 브랜치+PR만 |
| **일반 웹 페이지 조회** (doi.org, crossref, 저널 사이트) | ❌ | ✅ | 웹 세션은 네트워크 정책상 외부 HTTPS 차단. npm/pypi만 열려 있음 |
| **clasp login / GAS 배포** | ❌ | ✅ | 대화형 OAuth + 로컬 브라우저 필요 |

| 장시간 대용량 처리 | ✅ | ✅ | 웹은 디스크 할당량 유한 |

**웹 세션 확정 사양(260725 실측):** Node v22.22.2, npm 10.9.7, Python 3.11.15. clasp 미설치.
npm 레지스트리는 프록시 예외라 `npm i -g @google/clasp`는 되지만, **`clasp login`이 안 되므로 배포는 불가**하다.

## 3. 그래서 작업 분담

- **웹 세션**: 정본 md 작성·이관 검수, KB 스키마 설계, 리포 산출물 수정, Slack/Drive 대조, 문서화, 리포 PR.
- **로컬 세션**: clasp 셋업, 빌드 GAS 작성·배포, 역빌드 diff 검증, OK차트 자동화, 저널 원문 확인.
- **Cowork**: 위임 브리프 기반 L2 이관 같은 대량 반복 작업.

## 4. 실패 이력 — 되풀이 금지

| 시도 | 결과 | 결론 |
|---|---|---|
| 크롬 익스텐션 브릿지로 대용량 주입 (165KB) | 2회 동일 지점 붕괴 | 브라우저 주입으로 돌아가지 않는다. 경로를 clasp로 바꿔 문제를 제거 |
| "계정 통일이 빌드의 전제조건" | **과장, 철회** | 필요한 건 소유권 일치가 아니라 **접근 권한**. GAS는 실행 계정 권한으로 돈다 |
| DOI로 자체 논문 서지 확정 (웹 세션) | 실패 | 해당 저널은 **PubMed 비색인**이고, doi.org·crossref는 웹 세션에서 차단. → 로컬 세션 또는 저널 원문 PDF로만 확정 가능 |

권한 관련 안전장치: 빌드 GAS 첫 단계에 **"정본 폴더 읽기 시도 → 실패 시 슬랙 경보"**. 권한이 끊겨도 조용히 실패하지 않게 한다.

## 5. 착수 순서 (기획 정본 §5 요약 — 상세는 Drive 정본)

1. clasp 셋업 (Apps Script API 켜기 → node 확인 → clasp 설치 → login) — **로컬**
2. L2 이관 a~d — Cowork 위임. 완료조건: KB 건수 = 원본 행 수(누락 0 증명)
3. 빌드 GAS 작성 — clasp 경유. 권한 자가진단 포함
4. 역빌드 검증 — 정본에서 컴파일한 결과 vs 현행 시트 **diff 0**. 통과 전 전환 금지
5. 전환 + 드리프트 감시 가동
6. L3 파일럿 1도메인 (전 자산 일괄 색인 금지)
7. 실패 회수 루프 연결

## 6. 판단 원칙

- **RAG는 절대 1순위가 되지 않는다.** 정본 히트 우선, 미스일 때만 RAG 보조. (구가격 오염 차단)
- 다음 모델 업데이트를 기다리며 착수를 미루지 않는다. 현재 능력의 바닥선에서 돌아가게 짓는다. 모델이 바뀌어도 두뇌는 남는다.
- 잘 지어질수록 커 보여야 하는 건 시스템이 아니라 **아크로한의원**이다. 그게 성공 판정 기준이다.
